# README presentation assets

The original owner-supplied `showcase.png` remains at the repository root.
`showcase-rounded.png` presents the same image inside a 40 px rounded frame;
its editable SVG frame is `tools/readme-cover.svg`. The image content and game
screens are unchanged. These are illustrative promotional assets, not proof
of physical-console validation.

Download, website and Discord buttons are editable SVG files. They use local
vector shapes and system font fallbacks; no external badge service is required.
The underlying game and trademark notices in the main README still apply.
